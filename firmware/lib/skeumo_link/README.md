# skeumo_link (vendored)

Signed BLE frames between the Skeumo fireplace lighter and Firewatch. This is a copy of
`core/lib/skeumo_link` from the [Skeumo](https://github.com/micahflock/Skeumo) repo, where it
is maintained and host-tested (SHA-256/HMAC test vectors, tamper and replay tests). Keep the
two copies identical: if the frame format changes there, copy the folder here again.
